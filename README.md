# [gitwip](https://4mbl.link/gh/gitwip)

> Lists non-primary Git branches and stashes in a directory tree.

### Installation

Use pip to install `gitwip`.

```bash
pip install --upgrade gitwip
```

## Usage

```bash
gitwip ~/code
```
